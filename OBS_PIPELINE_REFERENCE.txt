KEY DESIGN DECISIONS
====================

1. Absolute Deadline Scheduling
   next_frame_ns += interval  (NOT next_frame_ns = NOW + interval)
   → Prevents drift accumulation
   → Like OBS libobs architecture

2. Hybrid Sleep Strategy
   OS sleep + 1ms busy-wait
   → OS sleep (time.sleep) is efficient but ~1-10ms jitter
   → Busy-wait is CPU-intensive but nanosecond precision
   → Trade 1ms busy-wait per frame for nanosecond precision
   → Net: Acceptable CPU cost for stable, locked FPS

3. Frame Reuse on Capture Lag
   If no new frame available: emit last frame again
   → Like OBS (never skips frames, maintains output FPS)
   → Prevents dropped frames from camera lag
   → Display shows current content, not blank

4. Three-Frame Buffer
   maxlen=3 like OBS NUM_TEXTURES
   → Circular: always overwrites oldest
   → Never blocks capture or render
   → Balances latency vs. buffering

5. Separate Threads for Capture & Render
   Capture: Unrestricted speed (reads as fast as camera provides)
   Render: Fixed FPS (strict timing)
   → Decouples camera speed from output FPS
   → Capture can be 30fps, render at 60fps (will duplicate frames)
   → Capture can be 120fps, render at 60fps (will drop frames)

FRAME FORMAT
============

In FrameBuffer: BGR (OpenCV native)
├─ H × W × 3 channels
├─ GBR ordering (blue-green-red)
└─ From cv2.VideoCapture.read()

In Render Signal: BGR (unchanged from buffer)
└─ Emitted by RenderThread.frame_ready

In Main Handler: BGR → RGB conversion
├─ cv2.cvtColor(bgr, cv2.COLOR_BGR2RGB)
├─ RGB ordering for Qt display
└─ Passed to _on_camera_frame_ready()

In Qt UI: QPixmap/QImage
├─ RGB format expected by Qt
├─ Scaled to widget size
└─ Displayed via label.setPixmap()

TIMING CONSTANTS
================

Frame intervals (nanoseconds):
    24fps:   41,666,667 ns
    25fps:   40,000,000 ns
    30fps:   33,333,333 ns    ← Common streaming target
    48fps:   20,833,334 ns
    50fps:   20,000,000 ns
    60fps:   16,666,667 ns    ← Common monitor refresh rate
    120fps:   8,333,334 ns

Coarse sleep (ms):
    frame_interval - 1ms
    → 30fps: sleep ~32ms, busy-wait 1ms
    → 60fps: sleep ~15ms, busy-wait 1ms
